# UI 风格与布局规范

> 用户明确要求：**每次增加功能都必须沿用同一套视觉语言**，按钮、弹窗、间距不能各写一套。
> 新增界面前先读这份文档，能用现成组件的不要自己拼。

## 1. 颜色（只用 `UiPalette`）

| 用途 | 常量 | 值 |
| --- | --- | --- |
| 页面底色 | `PAGE` | `#eef8f1` |
| 卡片/弹窗底色 | `SURFACE` / `Color.WHITE` | `#ffffff` |
| 浅底/次要按钮 | `PALE`、`SOFT` | `#e7f7ee` / `#d7f0e1` |
| 主色（按钮、选中态） | `ACCENT` | `#1f8a5f` |
| 主文字 | `INK` | `#133226` |
| 次要文字/说明 | `MUTED` | `#5c7c6e` |
| 描边 | `BORDER` | `#cfe9da` |
| 危险/删除 | `WARN`、`WARN_SOFT` | `#a4672a` / `#fff2e2` |

不要写死十六进制颜色（`0xff...`），除非是新加的具名语义色，那就先加进 `UiPalette`。

## 2. 间距（8 的倍数）

- 页面左右内边距：**16dp**（列表页）/ **20dp**（标题区）
- 卡片内边距：**16dp 水平 / 13–14dp 垂直**
- 卡片之间：**8–10dp**
- 区块之间：**14–18dp**
- 列表底部留白：**96dp**（给右下角加号和底部导航让位置）
- 底部导航：高度 **64dp**，左右边距 14dp，下边距 10dp

## 3. 字号

| 用途 | 字号 | 粗细 |
| --- | --- | --- |
| 页面标题 | 22–26 | 粗 |
| 卡片主标题 / 列表项标题 | 15–16 | 粗 |
| 正文 | 14–15 | 常规 |
| 次要说明、时间 | 12–13 | 常规 |
| 标签（上方小字） | 11 | 常规 |

## 4. 控件高度

- 输入框、主按钮：**48dp**
- 小选项 chip：**36–40dp**
- 圆形加号 FAB：**56dp**，右下距 20dp / 底部距 86dp
- 列表行最小高度：**48dp**

## 5. 按钮

- 主操作：`ACCENT` 底 + 白色粗体字，圆角 **12–16dp**
- 次操作：`PALE`/`SOFT` 底 + `INK` 字
- 危险操作：`WARN_SOFT` 底 + `WARN` 字
- 同一行两个按钮必须**等宽（weight=1）+ 间距 6–12dp**，不要一大一小
- 文字按钮（如「＋ 加子任务」）用 `ACCENT`、12–13sp、不加背景

## 6. 弹窗

- **一律**用 `FormKit.showStyled(context, dialog)`，禁止 `dialog.show()` 裸弹
- **禁止** `AlertDialog.Builder.setItems(...)`：选项列表统一用 `FormKit.options(...)`
- 输入框统一 `FormKit.input(...)` / `FormKit.textInput(...)`（自带 `INK` 文字色、48dp 高、圆角背景）
- 时间选择用 `FormKit.timeField(...)` + `TimePickerDialog`
- 分段时间用 `FormKit.segmentGroup()` / `segmentOption()`
- 弹窗内容外层 padding：**18dp 水平 / 10dp 顶部**

> 教训：beta14 的任务长按菜单用了原生 `setItems`，系统默认样式，和 App 完全两个风格。

## 7. 页面结构

```
FrameLayout (根)
├── LinearLayout (垂直)
│   ├── 标题区（左右 20dp，上 16dp）
│   ├── ScrollView (weight=1) → 内容列表（左右 16dp，底部 96dp）
│   ├── 底部工具区（可选）
│   └── BottomNavigationBar (64dp)
└── FAB (56dp, 右下)
```

新建页面照抄这个骨架，不要再发明新的层级。

## 8. 任务 / 卡片 / 事项三个模块的约定

- **任务页列表行**：左侧 22dp 方格 checkbox + 右侧任务名（16sp），**不要**再加说明文字、开关、子任务列表
  - 点方格 = 勾选/取消完成；点行 = 进子任务页；长按 = `FormKit.options` 菜单
  - 已完成的移到列表底部：一条 `BORDER` 细线 + 「已完成 N 个 ⌄」，默认折叠，点标题展开
  - 第二天自动回到待办列表（完成记录按天判定，不需要手动清理）
- 卡片页列表行：左侧标题+副标题，右侧操作文字
- 子任务只在子任务页里出现；任务行不展开子任务，也不显示子任务数量
- 单条任务的提醒开关，放在长按菜单里，不占列表行位置

## 9. 提交前自检

1. 有没有用没样式的原生控件？
2. 同一功能的两个页面，外观是否一致？
3. 按钮高度是否都是 48dp、等宽对齐？
4. 最后一条内容会不会被 FAB / 导航挡住？
5. 数字输入框的文字颜色是否可见（别白底白字）？
