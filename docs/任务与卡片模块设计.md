# 任务 / 卡片 / 答题 三模块设计

> 状态：起草中（2026-11-07）。目标是复用现有「身体提醒」的调度、霸屏、记录、统计四条链路，只替换霸屏内容。

## 1. 模块划分

现有 App 只有一类东西：**事项（Rule）**。改造后事项带 `module` 字段，一个 App 里有四种：

| module | 名称 | 霸屏内容 | 统计归口 |
|---|---|---|---|
| `body` | 身体 | 现在的健康建议 + 表情动画（不变） | 身体 |
| `task` | 任务 | 任务标题 + 我的备注 + 「完成 / 没做」 | 任务 |
| `card` | 卡片 | 卡片正文（题目/知识点），只读展示 | 卡片 |
| `card` + `quiz` 标记 | 答题 | 一次弹一道题 → 输入回答 → 提交 → 退出 | 卡片（另看「答题记录」） |

`card` 和 `quiz` 共用一份「卡片集」数据，区别只是霸屏时给不给输入框。

## 2. 调度类型（在现有两种上补两种）

现有：`interval`（时间段内每 N 分钟）、`times`（每天固定几个时间点）。新增：

- `weekly`：每周指定星期几 + 指定时间点（`daysMask` 位掩码，周一=1 … 周日=64）
- `once`：指定日期 + 时间，只响一次（`onceAt` 毫秒时间戳）

允许一个事项有多个时间点，所有类型都以「下一次触发时刻」的形式交给 `ReminderScheduler`，其余逻辑不动。

## 3. 卡片集 JSON 格式

导入方式：`设置 → 卡片 → 导入 JSON`（文件选择器），文件名任意，内容如下：

```json
{
  "version": 1,
  "title": "高数 · 第三章",
  "mode": "quiz",
  "cards": [
    {
      "id": "c1",
      "question": "拉格朗日乘子法的几何意义是什么？",
      "answer": "可选，提交后展示",
      "note": "可选补充说明",
      "tags": ["高数"]
    }
  ]
}
```

- `mode`：`card`（只展示，默认）或 `quiz`（答题）
- `id` 缺省时按序号生成
- 导入时校验：`cards` 必须非空，`question` 必填；单次导入上限 2000 张
- 同名 `title` 重复导入 → 提示「覆盖 / 新建副本」

## 4. 存储

沿用 SharedPreferences，与现有代码一致：

- `reminder_rules_v2`：不变，存 `module=body` 的事项
- `reminder_rules_v3`：所有模块的事项统一存这里（带 `module`/`deckId`/`quiz`/`daysMask`/`onceAt`），读取时兼容 v2
- `card_decks_v1`：卡片集（JSON 原样存 + 导入时间）
- `health_records`：不变，`ReminderRecord` 增加 `module` 字段（旧记录按 `body` 处理）
- `quiz_answers`：答题记录（什么时候弹的、答了什么、耗时）

## 5. 统计

`StatsActivity` 顶部加模块切换：**身体 / 任务 / 卡片**。

- 身体：现有日历 + 做了/没做时间轴（不变）
- 任务：任务完成率、每条任务的历史、连续天数
- 卡片：展示次数 + 答题记录（题目、我的回答、参考答答案、耗时）

## 6. UI 入口

底部导航从「首页 / 统计」改为「首页 / 任务 / 统计」，任务页里再分「清单 / 卡片」两个 Tab。

## 7. 分阶段实施

1. **数据层**：Rule 加 `module`/`deckId`/`quiz`/`daysMask`/`onceAt`；Record 加 `module`；调度支持新类型
2. **任务清单**：增删改查、一键清空、可选每日重置、到点霸屏
3. **卡片导入**：JSON 解析 + 卡片集管理 + 卡片霸屏
4. **答题模式**：一次一题 + 输入 + 记录
5. **统计分区**
6. 回归：身体功能不受影响

每阶段推 `feature/task-cards` 分支，由 CI 编译验证后再合入 `main`。
