# 提醒事项定点提醒

## 功能

每条提醒事项可以选择按固定间隔提醒，或按每天指定的时间点提醒。指定时间通过时、分、秒滚轮设置，可添加多个时间点，也可删除不需要的时间点。

## 使用方式

在“提醒事项”中新建或编辑事项，选择“按间隔”或“指定时间点”。选择指定时间点后，添加一个或多个时间并保存；提醒名称、启用状态和每日目标仍可按需设置。

## 提醒行为

- 到达所选时间后，手机正在使用时显示全屏提醒；息屏时沿用息屏闹钟设置。
- 每个时间点每天提醒一次。错过的时间点不补发，之后继续等待下一个时间点。
- 修改系统时间或时区后，会按当前本地时间重新计算提醒。
- 每日目标和“达标后是否继续提醒”仍按事项中的设置执行。

息屏响铃需要开启应用的息屏闹钟和声音或振动设置，并允许相关通知与闹钟权限。系统省电策略可能影响实际触发时间。
