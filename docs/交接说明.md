# 交接说明（给下一个接手的 AI）

> 最后更新：2026-11-07，对应版本 v0.2.0-beta5

## 1. 项目背景

安卓 App「休息豆芽」，包名 `io.iftech.healthreminder`。最初是本地健康提醒工具（喝水 / 护眼 / 走动，到点全屏霸屏提醒 + 记录 + 日历统计）。现在扩展成四个模块：

| 模块 | 说明 | 霸屏页 |
|---|---|---|
| 身体 body | 原有健康提醒，未改动 | `ReminderActivity` |
| 任务 task | 每日任务清单、打卡 | `TaskReminderActivity` |
| 卡片 card | JSON 导入的卡片集，逐张展示 | `CardReminderActivity` |
| 答题 quiz | 卡片集的答题模式，弹一题→输入→记录 | `CardReminderActivity`（`quiz=true`） |

- 仓库：`git@github.com:qiuyinlan/reminder_rest.git`（public，默认分支 `main`）
- 本地路径：`/root/.openclaw/workspace-bot4/reminder_rest`
- 技术栈：Java + Gradle（AGP 8.10.1 / Gradle 8.11.1 / compileSdk 35 / minSdk 26），纯代码构建 UI，无 XML 布局，数据存 SharedPreferences

## 2. 环境限制（重要）

1. **服务器没有 Android SDK**，不能本地编译。所有编译验证靠 GitHub Actions，push 后约 4-6 分钟出结果。
2. **服务器直连 github.com:443 被墙**：
   - git 操作走 SSH（22 端口，密钥已配好，可直接 push）
   - 下载 release 资产用代理：`https://ghfast.top/https://github.com/...`
   - `api.github.com` 可用，查 CI 状态、release 用它
3. GitHub CLI 装了但没有 token（device flow 走不通），不要依赖 `gh auth`。

## 3. CI / 发版规则

- push 到 `main` 或 `feature/**` 自动编译：workflow `Android Build`，绿了才算写完
- 打 tag 自动发版：workflow `Release APK`
  - `v0.2.0` 形式 → 正式通道，更新 `update-manifest.json`
  - `v0.2.0-beta5` 形式（带横杠）→ 测试通道，更新 `beta-manifest.json`，不污染正式版
- 签名：
  - 测试通道用仓库内固定密钥 `ci/beta-signing/restbean-beta.jks`（密码见同目录 `credentials.properties`），保证 beta 之间可覆盖升级
  - **将来用户提供正式 keystore 后**：加 GitHub Secrets 四件套 `RELEASE_KEYSTORE_BASE64` / `RELEASE_STORE_PASSWORD` / `RELEASE_KEY_ALIAS` / `RELEASE_KEY_PASSWORD`，workflow 已有读取逻辑且 secrets 优先
  - 注意：换签名的那一次，用户必须卸载重装
- versionCode：正式版从 `update-manifest.json` 自增，beta 从 `beta-manifest.json` 自增，别混用

## 4. 已完成（v0.2.0-beta5）

**数据层**
- `ReminderSettings.Rule` 新增字段：`module`(body/task/card)、`deckId`、`quiz`、`daysMask`（每周位掩码，周一=1…周日=64）、`onceAt`（单次时间戳）
- 调度支持四种：每天固定点 / 每周指定星期 / 单次定时 / 时间段内每 N 分钟
- `ReminderRecord` 新增 `module` 字段，旧记录默认 body

**任务**
- `TaskActivity`（底部导航第 2 个 Tab）：增删改、一键清空、重置今日、每日自动重置开关（默认关）
- 到点弹 `TaskReminderActivity`：完成 / 5 分钟后 / 今天不做

**卡片**
- `CardDeck`：JSON 解析与存储；`CardActivity` 走 SAF 文件选择器导入、管理卡片集、排时间点
- `CardReminderActivity`：逐张轮播，答题模式写 `QuizLog`
- 格式见 `docs/示例卡片集.json`

**统计**
- `StatsActivity` 顶部 身体 / 任务 / 卡片 三区分流；卡片区有答题概览

**UI 规范**
- `FormKit.java`：把「添加事项」那套弹窗视觉语言抽成工具类，新页面都该用它，别用系统原生 AlertDialog / TimePickerDialog
- 所有新页面必须调 `UiPalette.applyWindow(getWindow())`，否则 Android 15 全屏会顶到状态栏

## 4.5 经期标记与身体数据导出（新增）

**数据层** — 全部只存本机
- `UserProfile`（prefs `user_profile`）：性别 `female` / `male` / 空（不指定）
- `PeriodLog`（prefs `period_log`）：键 `period_yyyy-MM-dd`（开始日），值 = 结束日或空字符串（进行中）。同一天开始只保留一条
  - 日历渲染按 ISO 日期字符串直接比较，跨月/跨周自动按行分段圆角
  - 忘记点结束时，下次点「来了」会自动收尾上一段（最多按 10 天算），避免粉色线跨月拉满
- `DailyBodyNote.all(context)`：给导出用的全量读取

**UI**
- 设置 →「个人资料」：女生 / 男生 / 不指定；选女生后首页身体卡出现「今天来了 / 今天结束」，统计身体区出现「经期记录」卡（按日历选中日期标记开始/结束、删除最近一次）
- 统计日历：经期日期画粉色连线（`UiPalette.PERIOD_FILL / PERIOD_INK / PERIOD_STRONG`），并在日历下方显示图例
- 设置 →「数据」→ `BodyExportActivity`：日期范围 / 月份 / 全部；用 `ACTION_CREATE_DOCUMENT` 导出 CSV（UTF-8 BOM，Excel 可直接打开）
- CSV 列：`日期,类型,详情`，类型为「身体记录」或「经期」
- 设置 →「数据」→ `BodyImportActivity`：`ACTION_OPEN_DOCUMENT` 选 CSV，`BodyDataImporter` 解析（RFC4180 引号字段），可「合并导入」或「清空本机后导入」；换设备迁移用这个

## 5. 踩过的坑

- 每个 GitHub runner 是全新机器，自动生成的 debug 签名每次都不同 → APK 无法覆盖安装。已用固定密钥解决。
- `app/build.gradle` 的签名配置已改成「只有配了 keystore 才应用 release 签名，否则回落 debug」，否则 CI 直接报 `path may not be null or empty string`。
- CI 失败时看不到日志（`actions/runs/{id}/logs` 需要 admin token）。`Android Build` workflow 里加了失败自动把日志推到 `ci-log` 分支的机制，`git clone -b ci-log` 即可读。
