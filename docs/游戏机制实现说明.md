# 游戏机制实现说明

## 核心设计（来自闪应用闯关课堂）

把「坚持」拆成每天只花几分钟的小份量，再用即时奖励和「不想断」的心理把人留住。

### 五件套骨架

1. **每日额度制** - 把大目标切成「今天只做一点点」
2. **即时反馈** - 打卡瞬间给动画、音效、夸奖
3. **批次激励** - 每 7/21/66 天宝箱奖励
4. **弹性补签** - 漏了一天不清零，可补签（最多 3 天）
5. **进度可视化** - 连胜数字 + 宝箱进度

- 副标题：「连胜、宝箱、补签，让坚持更有趣」
- Switch 开关控制启用/禁用

#### `Habits.java`
修改 `toggleCompletion()` 方法：
- 完成打卡时自动更新连胜

- 仅在游戏化启用时生效

#### `HabitEditor.java`
在编辑页面头部添加进度卡片（游戏化启用时显示）：
- 🔥 连胜 X 天
- 🎁 宝箱可领取（达到里程碑时）
- 再坚持 X 天解锁宝箱

## 使用说明

1. **启用游戏化**
   - 设置 → 提醒与权限 → 游戏机制（打开开关）

2. **查看进度**
   - 编辑习惯时，头部显示连胜和下一个宝箱

3. **打卡完成**
   - 在任务页勾选习惯，自动更新连胜

## 技术细节

### 存储结构
- `game_settings` - 开关状态
- `game_progress` - 连胜、完成记录、补签、宝箱领取

### 习惯 Key 生成
```java
String habitKey = GameProgress.makeHabitKey("habit", habitId);
// 例如："habit_1"
```

### 连胜计算逻辑
- 昨天完成 + 今天完成 = 连胜 +1
- 昨天未完成 = 从 1 重新开始
- 取消今天完成 = 重置为 0

### 里程碑检查
```java
Integer chestAvailable = GameProgress.checkChestAvailable(context, habitKey);
// 返回 null 或可领取的里程碑天数（7/21/66）
```
